# GARUDA Billing (v1.11) — Installation Guide

## System Requirements
- **Device:** Android Smartphone or Tablet
- **OS Version:** Android 7.0 (Nougat) up to Android 16 (API 36)
- **RAM:** Minimum 2 GB (Recommended 4 GB+)
- **Storage:** 50 MB free space
- **Connectivity:** 100% Offline (No Internet required for billing or database)

---

## Step-by-Step Installation

### Step 1: Transfer or Download APK
- Transfer `GARUDA_Billing_v1.11_Release.apk` to the target Android phone via WhatsApp, USB Cable, or SD Card.

### Step 2: Allow Unknown Apps / Sideloading
- Tap on `GARUDA_Billing_v1.11_Release.apk`.
- If Android prompts *"For your security, your phone is not allowed to install unknown apps from this source"*:
  1. Tap **Settings**.
  2. Toggle **Allow from this source** to **ON**.
  3. Tap the Back button.

### Step 3: Complete Installation
- Tap **Install**.
- Android Package Manager will complete installation in ~5 seconds.
- Tap **Open**.

### Step 4: Microphone Permissions (For Hindi Voice Billing)
- On first launch, when prompted for *"Allow Garuda Billing to record audio?"*, select:
  - **"While using the app"** (App use karte waqt allow karein).
- This enables instant offline Hindi voice recognition.
