## 4. Remediation / Patch Recommendation (Engineering)
Send `X-Frame-Options: DENY` or `SAMEORIGIN` and `Content-Security-Policy: frame-ancestors 'self'` on all authenticated routes.

**Patch checklist:**
- [ ] Validate fix: `curl -i https://example.com/login` should return 404/403 without secrets and without SPA false-positive.
