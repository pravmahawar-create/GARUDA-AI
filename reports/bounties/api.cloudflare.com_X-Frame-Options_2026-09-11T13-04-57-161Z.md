**Business / Security Impact:** Information disclosure, clickjacking, or tech stack fingerprinting aiding further exploitation.

## 4. Remediation / Patch Recommendation (Engineering)
Send `X-Frame-Options: DENY` or `SAMEORIGIN` and `Content-Security-Policy: frame-ancestors 'self'` on all authenticated routes.

**Patch checklist:**
- [ ] Validate fix: `curl -i https://api.cloudflare.com` should return 404/403 without secrets and without SPA false-positive.
- [ ] Add regression test: assert sensitive path returns 404 and CORS does not reflect arbitrary origin.
- [ ] Deploy behind WAF/CDN with strict origin allowlist.
