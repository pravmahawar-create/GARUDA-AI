## 2. Technical SEO Architecture & Governance Rules

### Rule 1: Strict Canonical Protocol (`https://www.garudaos.in/`)
- All canonical tags, sitemaps, OpenGraph links, Twitter cards, and Schema.org `@id`s MUST use `https://www.garudaos.in/...`.
- Non-www (`https://garudaos.in`) must permanently 308 redirect to `www`.
- Never include non-www or redirecting URLs in `sitemap.xml`.

### Rule 2: Multi-Node Schema.org Graph Strategy
Every public template must deliver valid JSON-LD structured data:
1. **Homepage (`/`):** `Organization` + `SoftwareApplication` + `ProfessionalService` + `WebSite`.
2. **Entity Guide (`/what-is-garuda-ai`):** `AboutPage` / `Article` + `FAQPage`.
3. **Service Pages (`/services/:slug`):** `Service` + `BreadcrumbList` + `Offer`.
4. **Scoping Chat (`/chat`):** `WebApplication`.

### Rule 3: Privacy & Admin Protection
- Internal administrative, payment, proposal, and session routes MUST be disallowed in `robots.txt` and serve `<meta name="robots" content="noindex, nofollow" />`:
  - `/founder`
  - `/founder/acquisition`
  - `/revenue`
  - `/api/`
  - `/app`
  - `/pay/`
  - `/proposal/`
  - `/login`
  - `/signup`

### Rule 4: Crawlability & Non-JS Fallback
- `frontend/index.html` must maintain a high-quality `<noscript>` fallback detailing all core services and architectural links so basic crawlers (and headless spiders) index the page content immediately without relying solely on client-side JavaScript execution.
