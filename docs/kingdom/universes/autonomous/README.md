> Recovery status: **RECOVERED (purpose) / IMPLEMENTED (Mother Brain code exists).**

## 1. Mission

Give GARUDA the ability to discover goals, plan work, decide, execute, validate, learn from
execution, and continuously improve — always within Founder governance.

**GOVERNANCE RULE:** autonomous does not mean uncontrolled.

## 2. Scope

- Inside: scanning, goal-setting, planning, decision, execution, validation, reporting, learning,
  self-engineering, workforce orchestration.
- Outside: any action that bypasses founder approval.

```
SCAN → UNDERSTAND → GOAL → PLAN → DECIDE → EXECUTE → VALIDATE → REPORT → LEARN → IMPROVE → REPEAT
```
