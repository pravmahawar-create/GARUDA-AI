## 3. Permanent Organic Acquisition Flywheel

```
1. Google Search Query (e.g. "custom AI development company")
       │
       ▼
2. Prerendered Service Landing Page (https://www.garudaos.in/services/custom-ai-development)
   - Crawler visible: Title, Description, H1, Problem/Solution, Deliverables, Pricing, FAQ Schema
       │
       ▼
3. Visitor Engagement:
   - Understands exact technical capability and milestone transparency
   - Clicks "Get Project Scope" (smooth scrolls to form) or "Talk to AI Architect"
       │
       ▼
4. Project Scope Form Submission:
   - Captures Name, Work Email/Phone, Budget Tier, Requirements brief
   - Ingests UTM parameters (Campaign, Referrer, Search Keyword)
       │
       ▼
5. Instant API Intake (POST /api/inbound/project-scope):
   - Generates unique Scope Reference ID (#scope_...)
   - Durably persists lead to MongoDB & Supabase
   - Transmits immediate Telegram alert to Founder
       │
       ▼
6. Client Success Screen & Fast-Track Handoff
```
