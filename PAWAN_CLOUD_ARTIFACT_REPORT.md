### 2.1 The Artifact Manifest Structure
Every generated deliverable produces a structured manifest:
```json
{
  "artifactId": "art_task_pwn_1793477060536_990ee5_1793477060813",
  "taskId": "task_pwn_1793477060536_990ee5",
  "projectId": "cloud_independence_demo",
  "file": "dental-intake.html",
  "sha256": "69e31884a55f705c92021998e8f94b2f436a1fe70c004700d386af9096631f40",
  "sizeBytes": 284,
  "createdAt": "2026-10-31T20:04:20.813Z",
  "downloadUrl": "/api/pawan/artifacts/art_task_pwn_1793477060536_990ee5_1793477060813"
}
```

### 2.2 SHA-256 Cryptographic Integrity Guarantee
In compliance with Section 1 of the GARUDA Constitution:
- The SHA-256 digest is computed deterministically from the raw generated bytes before storage.
- When an artifact is downloaded, the server verifies that the digest of the payload matches the manifest hash. If any byte was corrupted or altered, the download is rejected with `INTEGRITY_VERIFICATION_FAILED`.

### 2.3 Expiration & Retention Governance
- **Retention Policy:** Artifacts generated in active client projects are permanently indexed.
- **Disk Governance:** Temporary benchmark artifacts are tagged with `ephemeral: true` and cleared after 7 days if disk utilization exceeds 80%, ensuring compliance with Render's disk limits.
