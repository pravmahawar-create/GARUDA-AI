# 🦅 GARUDA Sovereign AI & WhatsApp Bot Starter Kit (Next.js 14 + Supabase + Payments)

Build and deploy production-grade, 24/7 autonomous WhatsApp AI triage bots and high-converting PWAs in under 1 hour.

## 🚀 Key Features
- **Next.js 14 App Router & Tailwind CSS**: Sub-second loading, dark cyber modern theme.
- **WhatsApp Webhook Receiver**: Built-in verification, interactive appointment booking, patient triage.
- **50/50 Milestone Payments**: Pre-integrated Razorpay & Stripe webhooks.
- **Supabase PostgreSQL Schema**: Zero cold-start latency, resilient multi-tenant storage.
- **1-Tap QR Patient Intake PWA**: Works on mobile Safari & Chrome with zero app downloads.

## 🛠️ Quick Start
```bash
git clone https://github.com/pravmahawar-create/GARUDA-AI.git
cd packages/sovereign-ai-boilerplate
npm install
npm run dev
```
